# data-viz：绘制数据可视化图

> 来源：`../routine/彩图：绘制数据可视化图.txt`
> 触发：给文档配数据可视化图表（柱状图、折线图、饼图等）。
> 通用规范：SKILL.md §2.3（matplotlib 中文字体、按数据特点选图型）。工具：`edit_file` / `convert_docs_to_markdown`（见 `../tools.md`）。

## 要求

1. 给文档配数据可视化图表，如柱状图、折线图、饼图等，用于展示数据分析结果、性能对比、统计信息等。
2. 可以使用 Python 的 matplotlib、plotly 等库生成图表，或采用 SVG 直接绘制简单图表。
3. 配的图要位于 `images/` 文件夹下，需要根据数据特点选择合适的图表类型：
   - 趋势数据 → 折线图
   - 分类对比 → 柱状图
   - 占比 → 饼图
4. 请将用户的已有文档转为 markdown 格式，或生成新的 markdown 文件，在这个 markdown 文件中绘图。
5. 如果用户没有指定文档数量，则尽量写入多个文档，每个文档一个图。
