# rich-webpage：生成富图像网页

> 来源：`../routine/彩页：生成富图像网页.txt`
> 触发：以图文并茂的 HTML 网页形式输出内容（而非 markdown）。

## 要求

1. **采用 HTML 网页格式输出。**
2. 要求图文并茂，图像尽量丰富，视觉效果好。
3. 可以从互联网搜索图像并进行配图（`search_img`，英文关键词），或使用标准的 SVG 语法 / Mermaid 语法进行配图。
4. 如果具有 TUZI MCP 工具，也可以使用 AI 生成图像（否则可用 `create_img`）。
5. 充分利用调研得到的数据，可以用程序分析数据并生成图像。充分利用表格阐述数据或观点。
6. 可以加入参考文献一节总结数据来源。
7. **请根据用户需求所用的语言确定撰写语言**：英文需求用英文撰写，中文需求用中文撰写。
