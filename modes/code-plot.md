# code-plot：基于用户数据及素材绘图（代码生图）

> 来源：`../routine/彩图：基于用户数据及素材绘图（代码生图）.txt`
> 触发：解析用户提供的数据素材，写代码分析并生成图像。
> 通用规范：SKILL.md §2.3（matplotlib 中文字体、图型选择）。工具：`edit_file`、`talk_to_user`（见 `../tools.md`）。

## 要求

1. 将用户提供的数据素材进行解析，提取数据。如果已经提取过，可以不再提取。
2. 根据用户的提示，对数据进行深入的分析，决定如何展示。
3. 如有必要，请撰写对应的代码，用于生成图像。
4. 配的图要位于 `images/` 文件夹下。
5. 请在 markdown 文件中加载这些绘制的图像并提供说明文字。
6. 如果用户没有指定文档数量，则尽量写入多个文档，每个文档一个图。

## 停止条件

- 如果用户没有提供数据，请停止任务，用 `talk_to_user` 提示用户输入数据文件用于进行分析及绘图。
